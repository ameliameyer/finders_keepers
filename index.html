My Job Search Workflow

Find, evaluate, prepare, apply, track and develop skills in one connected workflow.

1. Find opportunities

Review your automated Daily Analytics Job Shortlist at 7 AM PT on weekdays. Select promising employer postings and copy their URLs.

Browse job sites

2. Analyze and qualify opportunities

Paste the original employer posting URL into the dedicated ChatGPT job-processing conversation. Review verified salary, remote and California eligibility, qualifications, fit score, strengths, gaps and red flags. Only archive qualifying jobs with a fit of at least 80/100 and a published minimum base salary of at least $80,000. Flag uncertain eligibility before proceeding and check for duplicates.

3. Prepare your application automatically

For approved jobs, the private GitHub archive synchronizes the job to Applications as Saved. The resume workflow copies your Google Docs master resume, tailors verified experience and skills while preserving formatting, and attaches the document link to the application. Accessible employer application questions are collected and drafted using your verified experience, then synchronized to Application Questions as editable drafts. If questions are hidden behind sign-in, paste them into the job-processing chat. Existing edited answers are preserved.

4. Review and submit

Open the tailored Google Doc, verify accuracy and one-page formatting, and export the final PDF manually. Edit and approve suggested answers in Application Questions. Submit the application yourself on the employer website; nothing is submitted automatically.

5. Track application progress

After submitting, enter the actual Applied Date and set the status to Applied. Update the status as you progress. Use Posting Closed for an opportunity removed before you apply; leave Applied Date blank. Use Withdrawn for a withdrawn application or opportunity, retaining the actual Applied Date only if submitted. Status Updated Date tracks changes separately. Use Home for monthly application activity and Applications for searchable, filtered records.

6. Prepare for interviews and develop skills

Use Interview Prep to practice interview questions and Application Questions to reuse approved written responses. Review required skill frequency and skill gaps in Analytics, then work on those topics in Ducks In Order. Google Drive holds resume documents; the private GitHub archive holds job records, approved generation requests and document links.
